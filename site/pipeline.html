A. Check the models in ten minutes

A. 10분 안에 모형 확인하기

Download four files into one folder and run python kh_replicate.py. It rebuilds the index and re-estimates every headline model from the data, then sets your numbers beside ours.

파일 네 개를 한 폴더에 받아 python kh_replicate.py를 실행합니다. 자료에서 지수를 다시 만들고 대표 모형을 모두 다시 추정한 뒤, 그 값을 우리 발표값과 나란히 보여 줍니다.
